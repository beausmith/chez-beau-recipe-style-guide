# Chez Beau Recipe Style Guide

An opinionated style guide for writing clean, precise, scalable, and educational recipes — culinary school in standard, not home-cook casual.

**[Read the style guide →](chez_beau_recipe_style_guide.md)**

The guide is a living document: conventions are developed through real recipe work and documented as edge cases surface, rather than designed in the abstract.
